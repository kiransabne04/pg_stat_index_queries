# Contributing

1. Open an issue first for anything bigger than a bug fix.
2. Follow `AGENTS.md` (it applies to humans too): build warning-free, keep PG 15–18 working, add a test for every behaviour change, update docs and CHANGELOG.
3. Run `make test-all` before opening a pull request and paste the summary.
4. Synthetic data only in tests, benchmarks and examples.
